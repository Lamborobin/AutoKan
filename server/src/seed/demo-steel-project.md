# Project: Quality & Compliance Management

This board manages quality control documentation, safety compliance workflows, and process improvement tasks for Nordstahl's primary mill facility in Germany.

## Scope

- Standard Operating Procedures (SOPs) — drafting, review, and approval workflows
- Safety incident documentation and root cause analysis reports
- Planned maintenance checklists and equipment inspection records
- Supplier qualification documentation and audit preparation
- ISO 9001 / ISO 45001 compliance tracking and gap analysis

## Document Standards

All documents must follow Nordstahl's standard structure. Required sections in order:

1. **Purpose** — what this document covers and why it exists
2. **Scope** — which processes, equipment, or personnel it applies to
3. **Responsibilities** — named roles (not generic "staff") with specific obligations
4. **Procedure** — numbered step-by-step instructions
5. **Safety Notes** — ⚠️ prefix on any safety-critical step
6. **References** — relevant standards, regulations, or parent documents
7. **Revision History** — version number, date, author, summary of change

Additional rules:
- Metric SI units throughout — flag any imperial measurements
- Safety-critical steps marked with ⚠️ at the start of the step
- Version number and effective date in document header
- All roles referenced by job title, not by name

## Verification Checklist (Compliance Checker agent)

When verifying any document submitted to this board, check ALL of the following and report PASS or FAIL with a brief note on each:

1. All seven required sections present and in correct order
2. Safety-critical steps marked with ⚠️
3. Metric SI units used throughout — no imperial measurements
4. Version number and effective date present in document header
5. Responsibilities section lists specific job titles, not generic terms
6. Procedure section uses numbered steps, not bullet points
7. References section cites at least one standard or regulation
8. No ambiguous language ("as needed", "occasionally", "may") in safety or procedure sections

If any check FAILS, list exactly what needs to be corrected. Do not approve a document with any failing checks.
