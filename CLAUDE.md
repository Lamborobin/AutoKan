# Entry point

CLAUDE.md is where every reader of this repo starts — human, app agent, or dev-assistant. It identifies your role, then routes you to the file with your actual instructions.

## Which file is yours?

| You are… | Read next |
|---|---|
| An **app agent** — Coder, Code Test Runner, Planner, or any capability triggered by the runner registry, running INSIDE AutoKan on a board task | `APP-AGENT.md` — your complete instruction set from here on |
| An **AI dev-assistant** — collaborating with a human Requester/user to evolve the AutoKan platform itself | `DEV-ASSISTANT.md` — your complete instruction set from here on |
| A **human editing directly**, no AI involved | Nothing further — these files exist to constrain AI agents working on your behalf, not you |

App agents are prohibited from editing this file.

**What is this project**: Autonomous AI agent task orchestration system — a kanban board where AI agents (PM, Developer, Tester) work through tasks autonomously with or without human involvement.

**Purpose**: This tool manages the full lifecycle of a client's project through a kanban board operated by AI agents and humans together.
