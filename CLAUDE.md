# Entry point

> **Before starting any task, read every context file marked `Read` in the table below (always `docs/rules.md`).** Files marked `On demand` should be loaded only when the row's "Read when…" condition matches the task you're working on.

> **Do not edit this file** unless adding a new context file to the table below. All other content belongs in `docs/`.

## Context Files
| File | Load | Read when… |
|---|---|---|
| `docs/rules.md` | Read | Hard constraints that apply to every task — cannot be bypassed |
| `docs/agents.md` | On demand | Agent logic, flows, behavior prompts, instruction file system, escalation behavior |
| `docs/capabilities.md` | On demand | Capabilities, trigger logic, column-to-agent assignment, permissions |
| `docs/frontend.md` | On demand | Any file under `app/src/` |
| `docs/api.md` | On demand | Implementing, modifying, or calling API routes |
| `docs/architecture.md` | On demand | Architectural design choices, structural decisions, system design |
| `docs/decisions.md` | On demand | Before reversing or changing a significant design decision |
| `docs/upcoming-changes.md` | On demand | Before starting work that might overlap with planned features |

**What is this project**: Autonomous AI agent task orchestration system — a kanban board where AI agents (PM, Developer, Tester) work through tasks autonomously with or without human involvement.

**Purpose**: This tool manages the full lifecycle of a client's project through a kanban board operated by AI agents and humans together.
